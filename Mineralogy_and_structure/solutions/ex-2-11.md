## Statement

> The plot below shows the full grain size distribution of a soil with \(PI=20\%\) and \(LL=59\%\). Estimate: (a) the clay fraction of the soil, (b) the activity of the soil, (c) the swelling potential of the soil, and (d) asses the likely mineral content of this soil.

Figure-dependent, exactly as Example 2.10: the clay fraction lives only in `EX212.svg` and was decoded from the SVG rather than read by eye. Note the statement gives $PI$ directly here, where Example 2.10 gave $PL$ — the change is worth pointing out to students rather than smoothing over.

## Given / Find

- $PI = 20\ \%$, $LL = 59\ \%$, and the full grain size distribution in `EX212.svg`
- **Find:** (a) $C_F$, (b) $A$, (c) $S_P$ class, (d) the dominant clay mineral

## Assumptions

**"Clay fraction" means the percentage by mass finer than $0.002\ \mathrm{mm}$ — a size class, not a mineralogical one.** Same reading as Example 2.10, and the same reason for recording it: part (d) then asks what those particles are made of, which is a separate question with a separate chart. Here the point lands harder, because a soil that is nearly half clay-size turns out to hold the *least* active of the common clay minerals.

**$C_F$ is taken as $49\ \%$.** Decoding the curve gives $48.62\ \%$ finer at $0.002\ \mathrm{mm}$, and the figure's own construction line is drawn at exactly that value, with the label rounding it to $49\ \%$. Two significant figures is the resolution a printed log axis supports. Using $48.6\ \%$ instead gives $A = 0.41$ to two decimals either way, so nothing downstream moves.

**The swelling potential is reported as the chart's *class*, not a single number** — the Seed et al. (1962) chart is zoned by the contours $S_P = 1.5\ \%$, $5\ \%$ and $25\ \%$, so a point between two contours gives a band. The answer is "$1.5\ \% < S_P < 5\ \%$, i.e. Medium".

**The soil is inorganic.** $LL = 59\ \%$ with $PI = 20\ \%$ places the point in the region the USCS labels "MH or OH", and separating the two needs the oven-dried liquid limit ratio, which is not given. Taken as inorganic throughout. This does not affect the mineralogy answer — the Mitchell & Soga chart has mineral fields, not organic ones — but it is the standard omission and it is recorded rather than ignored.

**The mineral verdict rests on two pieces of evidence, not one.** The point sits below the A-line, which is the kaolinite side of the chart, but it sits at the *lower* edge of the printed kaolinite band, close to the halloysite field. The activity is what settles it — see step 5 and the Flags.

## Solution

The same four questions as Example 2.10 and, by design, the opposite soil: nearly half of this one is clay-size, yet it is barely plastic. Activity is what makes that contrast legible, because it divides the plasticity by the amount of clay carrying it and so reports on the *mineral* rather than on the recipe.

1. Clay fraction — the clay-size boundary is $d = 0.002\ \mathrm{mm}$; entering the GSD there and reading down to the "percent finer" axis gives $C_F = \mathbf{49\ \%}$
2. Activity — $A = \dfrac{PI}{C_F} = \dfrac{20}{49} = \mathbf{0.41}$, and $0.41 < 0.75$, so the soil is **inactive**
3. Swelling potential — entering the Seed et al. (1962) chart at $C_F = 49\ \%$ and $A = 0.41$ lands between the $S_P = 1.5\ \%$ contour (at $A = 0.33$ here) and the $S_P = 5\ \%$ contour (at $A = 0.54$), so $1.5\ \% < S_P < 5\ \%$ — a **Medium** swelling potential
4. Position on the plasticity chart — the A-line is $PI_A = 0.73(LL-20) = 0.73(59-20) = 28.5$; with $PI = 20$ the point sits $8.5$ **below the A-line**, and the U-line, $PI_U = 0.9(59-8) = 45.9$, is nowhere near
5. Dominant mineral — below the A-line is the kaolinite band, so the soil is dominated by **kaolinite**; the activity agrees independently, since $A = 0.41$ falls inside kaolinite's $0.3$–$0.5$ and below illite's floor of $0.5$

Worth saying out loud once, at the end, because it is the reason both examples exist: Example 2.10 and this one land in the **same** Medium swelling band from opposite directions — $20\ \%$ of a very active clay there, $49\ \%$ of an inactive one here. The product $A \times C_F$ is $31$ and $20$ respectively, which is just $PI$ back again; the chart's job is to say that the *same* plasticity means different things depending on how much clay is doing the work.

import math

# ---------------------------------------------------------------- given
LL, PI = 59.0, 20.0

# ------------------------------------------- 1. read C_F off EX212.svg
# Same machinery as Example 2.10: the figure is matplotlib output re-saved by
# Inkscape, so the axes survive as tick <use> elements and the curve as one
# cubic Bezier. Nothing is read off a picture by eye.
XL, XR = 28.508724, 253.88414        # log10(d) = +2 .. -4   (outer SVG units)
YB, YT = 149.28413, 2.9112773        # 0 % finer .. 100 % finer
x_of_d = lambda d: XL + (2 - math.log10(d))/6*(XR - XL)
d_of_x = lambda x: 10**(2 - (x - XL)/(XR - XL)*6)
p_of_y = lambda y: (YB - y)/(YB - YT)*100

# curve, path id="path4": m 69.711484,2.9112786 c 121.584986,0  105.581706,83.8046894  172.865206,92.8646424

P = [P0] + [(P0[0]+dx, P0[1]+dy) for dx, dy in
            [(121.584986, 0), (105.581706, 83.8046894), (172.865206, 92.8646424)]]
bez = lambda t, i: ((1-t)**3*P[0][i] + 3*(1-t)**2*t*P[1][i]
                    + 3*(1-t)*t**2*P[2][i] + t**3*P[3][i])

def pct_finer(d):
    xt = x_of_d(d)
    if not bez(0, 0) <= xt <= bez(1, 0):
        return None
    lo, hi = 0.0, 1.0
    for _ in range(200):
        m = (lo+hi)/2
        lo, hi = (m, hi) if bez(m, 0) < xt else (lo, m)
    return p_of_y(bez((lo+hi)/2, 1))

print("EX212.svg decoded -- same axis calibration as EX211.svg, re-checked here")

      % (abs(d_of_x(gx)-0.002)/0.002*100))

# ------------------------- 3. swelling potential, Seed et al. (1962) chart
X0, SX = 197.6259, 1.597989          # x_svg = X0 + C_F*SX
Y0, SY = 45.30666, 18.654733         # y_svg = Y0 - A*SY
xf, af = lambda cf: X0 + cf*SX, lambda y: (Y0 - y)/SY
cff = lambda x: (x - X0)/SX
rel = lambda p, *ds: [p] + [(p[0]+dx, p[1]+dy) for dx, dy in ds]
bz = lambda Q, t, i: ((1-t)**3*Q[0][i] + 3*(1-t)**2*t*Q[1][i]
                      + 3*(1-t)*t**2*Q[2][i] + t**3*Q[3][i])
bnd = {
 1.5: [rel((209.79357, -48.456171), (2.85292, 43.2703383), (4.56103, 80.233773), (62.25353, 87.187174)),
       rel((272.0471, 38.731003), (10.56584, 1.273449), (22.89206, 2.060709), (37.1704, 2.496304))],
 5.0: [rel((215.09427, -48.319471), (3.70232, 62.450848), (23.82958, 83.925138), (94.69676, 87.257298))],
 25.0: [[(223.06414, -48.56137), (234.8098, 8.7573363), (254.31851, 23.6371), (309.4638, 33.068188)]],
}

def A_boundary(segs, cf):
    xt = xf(cf)
    for Q in segs:
        if bz(Q, 0, 0) - 1e-9 <= xt <= bz(Q, 1, 0) + 1e-9:

            for _ in range(200):

                lo, hi = (m, hi) if bz(Q, m, 0) < xt else (lo, m)
            return af(bz(Q, (lo+hi)/2, 1))

print("   margin to the Low/Medium contour: %+.3f in activity; the Medium band is only %.3f wide here,"

print("   sensitivity: C_F read as 48 %% -> A = %.3f (%s);  50 %% -> A = %.3f (%s)"

PI_U = 0.90*(LL - 8)
print("plasticity chart (Mitchell & Soga): A-line PI = 0.73(LL-20), U-line PI = 0.9(LL-8)")
print("   A-line at LL = %.0f  ->  PI_A = %.2f      PI - PI_A = %+.2f  (BELOW the A-line)" % (LL, PI_A, PI - PI_A))
print("   U-line at LL = %.0f  ->  PI_U = %.2f      PI - PI_U = %+.2f" % (LL, PI_U, PI - PI_U))
print("   deck's own rule: kaolinites just below the A-line  ->  KAOLINITE")
print("   cross-check on activity, deck's table: kaolinite 0.3-0.5, illite 0.5-1.3, Ca-montmorillonite 1.5")
print("      A = %.2f falls inside kaolinite's 0.3-0.5 and below illite's floor -> same verdict" % A)
print("   nearest competitor on the chart is the halloysite field (LL 45-72, PI 5-17);")
print("      dehydrated halloysite has A = 0.5 and hydrated A = 0.1, so activity separates them:")
print("      A = %.2f is not 0.1, and PI = %.0f sits above that field -> kaolinite stands" % (A, PI))
print()
print("   USCS aside: LL = %.0f >= 50 with PI below the A-line makes this MH, an elastic silt --" % LL)
print("   a kaolinitic soil can be MH; the mineral question and the group symbol are separate questions.")
print()

# ------------------------------------- 6. contrast with Example 2.10
print("contrast with Example 2.10 (C_F = 20 %, A = 1.55, montmorillonite)")
print("   both land in the SAME Medium band by opposite routes:")
print("     Ex 2.10:  little clay (%2.0f %%) of a very active mineral (A = %.2f)" % (20, 1.55))
print("     Ex 2.11:  much clay (%2.0f %%) of an inactive mineral    (A = %.2f)" % (CF, A))
print("   product A x C_F:  Ex 2.10 -> %.0f    Ex 2.11 -> %.0f   (that product IS the PI)"
      % (1.55*20, A*CF))
print("   which is the point of the chart: swelling needs both the amount and the type of clay.")
print()

# --------------------------------------------------------- consistency
print("consistency checks")
print("   PI < LL:", PI < LL, " PL = LL-PI = %.0f > 0:" % PL, PL > 0,

print("   C_F = %.0f %% <= fines fraction %.1f %% (percent finer at the No. 200, 0.075 mm):"
      % (CF, pct_finer(0.075)), CF <= pct_finer(0.075))
print("   units: C_F and PI are percentages; A = PI/C_F is dimensionless; S_P a percentage volume change")
print("   magnitude: half the soil is clay-size, yet PI is only 20 % -- a lot of clay doing little work,")
print("              which is exactly what an activity below 0.75 means.")

The mineral identification agrees from two independent directions. On the plasticity chart, $(LL, PI) = (59, 20)$ sits $8.5$ below the A-line, on the kaolinite side, with the U-line $25.9$ away and irrelevant. On the activity table, $A = 0.41$ is inside kaolinite's $0.3$–$0.5$ and below illite's floor of $0.5$.
