## Statement

> Calculate the value of $T_v$ for degrees of consolidation equal to 50%, 90%, and 95% using the approximate solution.

## Given / Find

- $U = 50\%$, $90\%$ and $95\%$
- The approximations on the "Solution approximations" slide: $T_v = \dfrac{\pi}{4}\left(\dfrac{U}{100}\right)^2$ for $U < 60\%$, and $T_v = 1.781 - 0.933\log(100 - U)$ for $U \geq 60\%$
- **Find:** $T_{50}$, $T_{90}$, $T_{95}$

## Assumptions

None — the statement is complete. $\log$ is base 10, as in the approximation on the previous slide.

## Solution

Each value of $U$ is first checked against the range of validity on the "Solution approximations" slide, which decides which equation to use. This is the handwritten Principles line, "Approximation to solution".

1. $U = 50\%$ — $U < 60\%$, so $T_v = \dfrac{\pi}{4}\left(\dfrac{U}{100}\right)^2 = 0.25\,\pi\,(0.5)^2 = \mathbf{0.196}$
2. $U = 90\%$ — $U \geq 60\%$, so $T_v = 1.781 - 0.933\log(100 - U) = 1.781 - 0.933\log(100 - 90) = \mathbf{0.848}$
3. $U = 95\%$ — $T_v = 1.781 - 0.933\log(100 - 95) = \mathbf{1.129}$
