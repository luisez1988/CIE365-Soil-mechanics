## Statement

> Compute the total and effective horizontal stress at point A. Plot the horizontal total and effective stresses with the pore pressure profile in the same graph.

## Given / Find

- Layer 1, CL: $0$–$10\ \mathrm{ft}$, $\gamma_t = 115\ \mathrm{pcf}$, $K_0 = 0.50$, above the water table
- Layer 2, MH: $10$–$20\ \mathrm{ft}$, $\gamma_{sat} = 120\ \mathrm{pcf}$, $K_0 = 0.40$, below the water table
- Layer 3, SM: $20$–$30\ \mathrm{ft}$, $\gamma_{sat} = 135\ \mathrm{pcf}$, $K_0 = 0.60$, below the water table
- Ground water table at $z = 10\ \mathrm{ft}$
- Point A at $z = 23.5\ \mathrm{ft}$, inside the SM layer
- **Find:** $\sigma_{h,A}$, $\sigma'_{h,A}$, and the total horizontal stress, pore pressure, and effective horizontal stress profile with depth

## Assumptions

The soil profile is read from the figure `horizontal_example.svg`, again since the statement's text box carries no numbers. This profile is geometrically identical to Example 4.1's, same layers, thicknesses, water table depth, and point A, with a $K_0$ value added to each layer, so $\sigma'_{v,A}$ from Example 4.1 is reused directly here rather than recomputed. The coefficient of lateral earth pressure at rest that applies at a point is taken as the $K_0$ of the layer that point sits in, consistent with $K_0 = \sigma'_h/\sigma'_v$ being a ratio defined layer by layer, not a single value for the whole profile.

## Solution

At-rest horizontal effective stress is proportional to the vertical effective stress at the same point, $\sigma'_h = K_0 \sigma'_v$, and the total horizontal stress follows from the effective stress principle, $\sigma_h = \sigma'_h + u$.

1. Layer containing point A — A is at $z = 23.5\ \mathrm{ft}$, inside the SM layer ($20$–$30\ \mathrm{ft}$), so $K_0 = 0.60$ applies
2. Effective vertical stress at A, from Example 4.1 — $\sigma'_{v,A} = 1980.1\ \mathrm{psf}$
3. Effective horizontal stress at A — $\sigma'_{h,A} = K_0 \sigma'_{v,A} = 0.60 \times 1980.1 = 1188.1\ \mathrm{psf}$
4. Pore pressure at A, from Example 4.1 — $u_A = 842.4\ \mathrm{psf}$
5. Total horizontal stress at A — $\sigma_{h,A} = \sigma'_{h,A} + u_A = 1188.1 + 842.4 = \mathbf{2030.5\ \mathrm{psf}}$
6. Stress profile for the plot, evaluated at the layer interfaces and at A, using each layer's own $K_0$:

| $z$ (ft) | $K_0$ | $\sigma'_v$ (psf) | $\sigma'_h$ (psf) | $u$ (psf) | $\sigma_h$ (psf) |
|---|---|---|---|---|---|
| 0 | 0.50 | 0.0 | 0.0 | 0.0 | 0.0 |
| 10 | 0.50 | 1150.0 | 575.0 | 0.0 | 575.0 |
| 20 | 0.40 | 1726.0 | 690.4 | 624.0 | 1314.4 |
| 23.5 (A) | 0.60 | 1980.1 | 1188.1 | 842.4 | 2030.5 |
| 30 | 0.60 | 2452.0 | 1471.2 | 1248.0 | 2719.2 |

## Verification

```
sigma'_v,A (from Ex 4.1) = 1980.1 psf
K0 at A (SM layer)       = 0.6
sigma'_h,A = 0.6 * 1980.1                = 1188.06 psf -> 1188.1
u_A (from Ex 4.1)        = 842.4 psf
sigma_h,A  = 1188.06 + 842.4             = 2030.46 psf -> 2030.5

profile (K0, sigma'_h, sigma_h):
z= 0.0  K0=0.50  sigma'_h=   0.00  sigma_h=   0.00
z=10.0  K0=0.50  sigma'_h= 575.00  sigma_h= 575.00
z=20.0  K0=0.40  sigma'_h= 690.40  sigma_h=1314.40
z=23.5  K0=0.60  sigma'_h=1188.06  sigma_h=2030.46
z=30.0  K0=0.60  sigma'_h=1471.20  sigma_h=2719.20
```

Every value recomputed independently in Python from the $\sigma'_v$ and $u$ profile verified in Example 4.1. The legacy `EX450.svg` reports $\sigma'_{h,A} = 1189\ \mathrm{psf}$ and $\sigma_{h,A} = 2031\ \mathrm{psf}$, again one unit off from carrying the legacy solution's rounded $\sigma'_{v,A} = 1981\ \mathrm{psf}$ forward instead of the unrounded $1980.1\ \mathrm{psf}$ used here. Units check: $K_0$ is dimensionless, so $\mathrm{psf} \times (\text{dimensionless}) = \mathrm{psf}$. Magnitude check: horizontal stresses come out lower than the corresponding vertical stresses at every depth, as expected for $K_0 < 1$ throughout this profile.
