## Statement

> Solve problem 7.2 assuming $OCR=1.2$. Determine the primary consolidation settlement.

This is a cross-referenced example. Everything except $OCR$ comes from Example 7.2, which in turn takes the profile and the remaining data from Example 7.1. The values carried over are those computed in [ex-7-2.md](ex-7-2.md).

## Given / Find

- From Example 7.2: $\sigma'_{vo} = 153.4\ \mathrm{kPa}$, $\sigma'_{vf} = 353.4\ \mathrm{kPa}$, $e_0 = 1.026$, $H_0 = 10\ \mathrm{m}$, $C_r = 0.05$
- From Example 7.1: $C_c = 0.3$
- $OCR = 1.2$
- **Find:** $\delta_{pc}$

## Assumptions

Changing the $OCR$ does not change $w$, $e_0$ or the unit weights, so $\sigma'_{vo}$ and $\sigma'_{vf}$ are the same as in Example 7.2. Only $\sigma'_c$ changes.

## Solution

With a lower $OCR$ the preconsolidation stress may now sit below the final stress. If it does, the path runs along the recompression line up to $\sigma'_c$ and along the virgin line from there, and the two pieces add: $\delta_{pc} = \dfrac{H_0}{1+e_0}\left(C_r \log OCR + C_c \log\dfrac{\sigma'_{vf}}{\sigma'_c}\right)$.

1. Carry over the stresses — $\sigma'_{vo} = 153.4\ \mathrm{kPa}$, $\sigma'_{vf} = 353.4\ \mathrm{kPa}$, $e_0 = 1.026$ from Example 7.2
2. Check the case — $\sigma'_c = OCR \cdot \sigma'_{vo} = 1.2 \times 153.4 = 184.0\ \mathrm{kPa}$, so $\sigma'_{vf} > \sigma'_c$: case b, recompression then virgin compression
3. Recompression part — $C_r \log OCR = 0.05 \log 1.2 = 0.00396$
4. Virgin part — $C_c \log\dfrac{\sigma'_{vf}}{\sigma'_c} = 0.3 \log\dfrac{353.4}{184.0} = 0.0850$
5. Settlement — $\delta_{pc} = \dfrac{H_0}{1+e_0}\left(C_r \log OCR + C_c \log\dfrac{\sigma'_{vf}}{\sigma'_c}\right) = \dfrac{10}{2.026}(0.00396 + 0.0850) = \mathbf{0.439\ \mathrm{m}}$
