## Statement

> Solve problem 7.1 but assuming the clay has $OCR=4$, $w=38\%$, and $C_r=0.05$. All other values from Example 7.1 are unchanged.

This is a cross-referenced example. The profile ($9\ \mathrm{m}$ of sand with the water table at $3\ \mathrm{m}$, over $10\ \mathrm{m}$ of clay), the sand void ratio $e = 0.76$, $G_s = 2.7$ for the clay, $C_c = 0.3$ and $\Delta\sigma_v = 200\ \mathrm{kPa}$ come from Example 7.1 (`Consolidation/index.html`, slide "Example 7.1", and `FiguresGeneral/Profile_ex61.svg`).

## Given / Find

- Sand (from Example 7.1): $\gamma_{sat} = 19.01\ \mathrm{kN/m^3}$, $H_{sand} = 9\ \mathrm{m}$, water table at $3\ \mathrm{m}$
- Clay: $w = 38\%$, $S = 100\%$, $G_s = 2.7$, $OCR = 4$, $C_r = 0.05$, $C_c = 0.3$, $H_0 = 10\ \mathrm{m}$
- $\Delta\sigma_v = 200\ \mathrm{kPa}$ at mid-depth of the clay
- **Find:** $\delta_{pc}$

## Assumptions

The sand is unchanged from Example 7.1, including the assumed $G_s = 2.65$, so its unit weight $19.01\ \mathrm{kN/m^3}$ is carried over rather than recomputed.

"All other values are unchanged" is read as keeping $G_s = 2.7$ for the clay. Only $w$ changes, so $e_0$ and $\gamma_{sat}$ of the clay must be recomputed.

The $OCR$ is applied at the mid-depth of the clay, so $\sigma'_c = OCR \cdot \sigma'_{vo}$ at $z = 14\ \mathrm{m}$.

## Solution

The clay is now overconsolidated, so which compression index applies depends on whether the final stress passes the preconsolidation stress. Find $\sigma'_{vo}$ and $\sigma'_{vf}$ as in Example 7.1, then compare $\sigma'_{vf}$ with $\sigma'_c$. If $\sigma'_{vf} \le \sigma'_c$ the path stays on the recompression line and $\delta_{pc} = C_r \dfrac{H_0}{1+e_0}\log\dfrac{\sigma'_{vf}}{\sigma'_{vo}}$.

1. Initial void ratio of the clay — $e_0 = w G_s = 0.38 \times 2.7 = 1.026$
2. Unit weight of the clay — $\gamma_{sat} = \dfrac{\gamma_w (G_s + e_0)}{1+e_0} = \dfrac{9.81 (2.7 + 1.026)}{2.026} = 18.04\ \mathrm{kN/m^3}$
3. Initial effective stress at mid-clay — $\sigma'_{vo} = 9 \times 19.01 + 5 \times 18.04 - 9.81 \times 11 = 171.09 + 90.21 - 107.91 = 153.4\ \mathrm{kPa}$
4. Final effective stress — $\sigma'_{vf} = \sigma'_{vo} + \Delta\sigma_v = 153.4 + 200 = 353.4\ \mathrm{kPa}$
5. Check the case — $\sigma'_c = OCR \cdot \sigma'_{vo} = 4 \times 153.4 = 613.4\ \mathrm{kPa}$, so $\sigma'_{vf} < \sigma'_c$: case a, recompression line only
6. Settlement — $\delta_{pc} = C_r \dfrac{H_0}{1+e_0}\log\dfrac{\sigma'_{vf}}{\sigma'_{vo}} = \dfrac{0.05 \times 10}{2.026}\log\dfrac{353.4}{153.4} = \mathbf{0.0895\ \mathrm{m}}$
