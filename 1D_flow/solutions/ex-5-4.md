## Statement

> A laboratory falling-head permeability test is performed on a light-gray gravelly sand (SW), and the following data is obtained: $a = 7.25\ \mathrm{cm^2}$, $A = 11.43\ \mathrm{cm^2}$, $L = 11.62\ \mathrm{cm}$, $H_1 = 171.4\ \mathrm{cm}$, $H_2 = 79.3\ \mathrm{cm}$, $\Delta t = 110\ \mathrm{s}$ for the head to fall from $H_1$ to $H_2$. Calculate the permeability of the soil sample in cm/s.

The data arrives as a two-column list in the deck; all six values are in the HTML, so the example is self-contained.

## Given / Find

- $a = 7.25\ \mathrm{cm^2}$ (standpipe), $A = 11.43\ \mathrm{cm^2}$ (specimen), $L = 11.62\ \mathrm{cm}$
- $H_1 = 171.4\ \mathrm{cm}$, $H_2 = 79.3\ \mathrm{cm}$, $\Delta t = 110\ \mathrm{s}$
- **Find:** $k$ in $\mathrm{cm/s}$

## Assumptions

None — the statement is complete.

## Solution

Nothing maintains the head: the water in the standpipe falls, so $q$ changes continuously. Integrating Darcy's law over $\Delta t$ gives the falling-head equation $k = \dfrac{a L}{A\,\Delta t} \ln\dfrac{H_1}{H_2}$.

1. Which test, and why — the *apparatus* makes it falling-head, not the soil: nothing resupplies the standpipe
2. Sort out the two areas — $a$ is the standpipe cross-section (the water that falls), $A$ is the specimen cross-section (what the water flows through)
3. Head-ratio term — $\ln\dfrac{H_1}{H_2} = \ln\dfrac{171.4}{79.3} = \ln 2.161 = 0.771$ (dimensionless)
4. Geometric / time factor — $\dfrac{a L}{A\,\Delta t} = \dfrac{7.25 \times 11.62}{11.43 \times 110} = 0.0670\ \mathrm{cm/s}$
5. Permeability — $k = 0.0670 \times 0.771 = \mathbf{5.16 \times 10^{-2}\ \mathrm{cm/s}}$

## Verification

```
a*L/(A*dt)               = 0.067005
ln(H1/H2) = ln(2.1614)   = 0.77076
k = aL/(A dt) ln(H1/H2)  = 0.051645 cm/s -> 5.164e-02
```

Each value recomputed independently in Python. Units check: the head ratio is dimensionless, so the geometric term carries all the units, and $\Delta t$ is already in seconds — $k$ comes out in $\mathrm{cm/s}$ with no further conversion. Magnitude is the same order as Example 5.3, which is reasonable for a gravelly sand.

## Scaffolding decisions

Step 2 is an HTML table rather than prose. Swapping $a$ and $A$ is *the* classic error in this test, and here they differ by only a factor of 1.6 — so a swapped answer still looks plausible and will not be caught by a magnitude check. The table forces the distinction by naming what each area physically is.

Steps 3 and 4 deliberately split the formula into its dimensionless part and its dimensional part, so the unit reasoning is visible rather than buried in one substitution.

Red notes: apparatus versus soil; the $a$/$A$ trap; the head ratio being dimensionless; and where the units come from.

No `data-slide` short forms needed after trimming; every note fits the slide budget.

## Flags

The statement describes a gravelly sand (SW), which is coarse — a falling-head test is more usual for finer soils. This is not an error, but the note deliberately says the distinguishing feature is the *apparatus*, not the soil, to avoid teaching a false rule of thumb. An earlier draft of that note claimed the soil was "too fine", which contradicts the statement outright; it was corrected before the example was wired.
